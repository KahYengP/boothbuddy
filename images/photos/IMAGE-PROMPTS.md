# BoothBuddy event photos: prompts to regenerate them

Paste each prompt into an image tool (ChatGPT, Gemini, Midjourney, Firefly).
Save the result with the exact file name shown and put it in this folder (images/photos), replacing the old file.
No code changes are needed. The app picks the new photos up straight away.

## Sizes

- `event-N-venue.jpg` is the main photo. It shows on the Find Events cards and at the top of the event page. Use 4:3, around 1600 x 1200.
- `event-N-a.jpg`, `-b.jpg` and `-c.jpg` are the three venue photos under "Crowd and getting there". They open in the photo viewer. Use 4:3, around 1600 x 1200.
- `event-N-hero.jpg` is only a backup if the venue photo fails to load. Use 16:9, around 1600 x 900. It is optional.
- Save as JPG at about 80% quality, so each file stays under 500 KB.

## Style line (add it to the end of every prompt)

> Professional event photography, realistic, shot on a full-frame camera with a 35mm lens at eye level, soft natural light mixed with warm booth spotlights, clean and well organised, modern pop-up booth design with white system panels, small custom fascia signboards with simple made-up small business names, neat product displays, shallow depth of field, Singapore, no real brand logos, no watermark, no text overlay.
